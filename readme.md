## 🎯 Sobre o Projeto

<img align="right" alt="Coding" width="400" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif">

O **Valorant Players Hub** é uma aplicação web moderna e responsiva desenvolvida durante a **Imersão Dev da Alura com Google Gemini**. 

Este projeto permite aos fãs de Valorant pesquisar, filtrar e conhecer mais sobre os principais jogadores profissionais do cenário competitivo mundial.

### 💡 Motivação

Como fã de esports e entusiasta de desenvolvimento web, criei esta plataforma para combinar duas paixões: **programação** e **Valorant**!

### ⚙️ Instalação
```bash
# 1️⃣ Clone o repositório
git clone https://github.com/gabrielnfujii/imers-o_dev_Alura.git

# 2️⃣ Entre na pasta
cd imers-o_dev_Alura

# 3️⃣ Abra o index.html no navegador
# Ou use a extensão Live Server do VS Code
```
